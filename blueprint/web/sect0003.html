[Rank sum of a meldable vector] Source: half-formal.qmd, Lemma #lem-rank-sum. If \(d\) is meldable, then \(\operatorname {rankSum}(d)\equiv 0\pmod3\).

Proof ▶

Choose triplet counts \(t_i\) and run counts \(r_i\) witnessing meldability. A triplet at \(i\) contributes \(3i\) to the rank sum, while a run starting at \(i\) contributes \(i+(i+1)+(i+2)=3i+3\). Every contribution is divisible by \(3\); summing them proves the congruence.

  • Ninegates.scan_iff_scanDecomp

[Scan equals generalized decomposition] A scan of a vector from \(\sigma \) to \(\tau \) succeeds if and only if the vector admits the generalized coordinate decomposition from \(\sigma \) to \(\tau \).

Proof ▶

Induct on the vector length. The empty case records that the initial and final states coincide. For a nonempty vector, a successful first scan step gives the head triplet count and head start; the induction hypothesis handles the tail, and the shift lemmas translate tail coordinates and final outputs back to the original vector. Conversely, the head coordinate decomposition forces the first scan step to succeed, and the tail shift lemmas provide the decomposition needed by the induction hypothesis.

Lean declarations

  • Ninegates.meldable_iff_scanAccepts

[Canonical scan characterizes meldability] Source: half-formal.qmd, Lemma #lem-recurrence. A count vector is meldable if and only if its canonical scan is accepted.

Proof ▶

First suppose a meld decomposition is given. At each run start, replace groups of three identical runs by one triplet at each of their three ranks. This preserves the count vector and leaves every run count in \(\{ 0,1,2\} \). Inducting from left to right, the two incoming run counts are exactly the scan state. After subtracting them, the residual is \(3t_i+r_i\), so its residue modulo \(3\) is the normalized run count \(r_i\). The scan therefore follows these run counts, never fails, and ends at zero because no run starts in either of the final two positions.

Conversely, suppose the scan accepts. At coordinate \(i\), let \(s_i\) be the new second state component and let \(u_i=d_i-s_{i-2}-s_{i-1}\). Nonfailure gives \(u_i\geq 0\), and the transition rule makes \(u_i-s_i\) a nonnegative multiple of \(3\). Set \(t_i=(u_i-s_i)/3\). Then

\[ d_i=3t_i+s_i+s_{i-1}+s_{i-2}. \]

Acceptance says the final two run counts are zero, so these \(t_i,s_i\) form a legal meld decomposition.

In the finite-vector implementation, package the recurrence as the generalized decomposition from Lemma 41. In the forward direction, replace every original run count \(r_j\) by its residue \(r_j\bmod 3\) plus \(3\lfloor r_j/3\rfloor \); the quotient contributions are absorbed into the triplet counts. In the reverse direction, Lemma 42 rewrites the original meldability cover sum at coordinate \(i\) as exactly the incoming starts from \(i-2\), \(i-1\), and \(i\). The final two output equalities ensure that no run starts in the two invalid right-end positions.
