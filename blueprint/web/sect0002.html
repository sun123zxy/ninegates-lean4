2 The finite tile-count model

Write \([n]=\{ 1,\ldots ,n\} \). All coordinates in the mathematical description are one-based, even though an implementation may store them with zero-based finite indices.

[Removing a pair] If \(c_p\geq 2\), removing a pair at \(p\) means coordinatewise natural-number subtraction \(c-2e_p\). The definition is available for every \(c,p\); the inequality is imposed by statements that use it.

  • Ninegates.Meldable

[Meldability] Source: half-formal.qmd, Definition #def-meldable. A count vector \(d\) of length \(m\) is meldable if there are nonnegative triplet counts \(t_i\) and run-start counts \(r_i\) such that

\[ d_i=3t_i+r_i+r_{i-1}+r_{i-2} \]

for every \(i\in [m]\). Run counts outside \(1,\ldots ,m-2\) are interpreted as zero. Thus no run may extend beyond the right endpoint.

[Live all-rank wait] Source: half-formal.qmd, Definition #def-live-wait. A count vector \(c\) is a live all-rank wait if: every coordinate is at most \(3\), its total is \(n+4\), and \(c+e_x\) is complete for every \(x\in [n]\).

[The standard hand] Source: half-formal.qmd, finite-size reduction section. The standard count vector \(G_n\) has multiplicity \(3\) at the two endpoints and multiplicity \(1\) at every internal rank. The definition is made uniformly for all \(n\); the structural theorems only use \(n\geq 6\).
